01

Plant Disease Classification using Neural Networks

Developed a convolutional neural network to classify plant leaf diseases across multiple species. The model was trained on a dataset of over 20,000 images and achieved 89% classification accuracy — enabling faster, automated detection of crop diseases that would otherwise require expert manual inspection. The project covers the full ML pipeline: data preprocessing and augmentation, model architecture design, training, evaluation, and performance analysis.

02

Autonomic Hydroponic System with Real-Time Monitoring

Designed and implemented a self-managing hydroponic system prototype using IoT-connected embedded devices. The system integrates Autonomic Computing techniques to handle self-monitoring, self-regulation, self-healing, and auto-optimisation of resources — with all sensor data streamed and visualised in real time. Published and presented at the 9th International Conference on Control, Mechatronics and Automation (ICCMA 2021).

03

Land Cover Classification via Satellite Image Segmentation

Applied unsupervised machine learning to identify areas of forage loss from satellite imagery. Using the K-Means clustering algorithm, distinct colour clusters were extracted from the images and used to create masks that differentiate biomass-rich areas from barren land — providing a scalable, low-cost method for environmental and agricultural monitoring across large geographic areas.

04

RFM Customer Segmentation & Behavioural Cohort Discovery

End-to-end ML pipeline built on real Australian payment transaction data at DataMesh Group. Applied K-Means clustering to normalised RFM vectors to automatically discover five interpretable customer cohorts — including "Tradies" (early morning energy drink & meat pie buyers), "Young Professionals" (petrol + restaurants), and "Budget Families" (fast food regulars). Full stack: AWS → Python pipeline → PostgreSQL → Node.js API → React dashboard. Features an interactive spinning 3D cluster visualisation.
