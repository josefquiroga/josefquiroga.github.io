IEEE 2021

Autonomic Hydroponic System with Real Time Monitoring

9th International Conference on Control, Mechatronics and Automation (ICCMA 2021)

Nuñez Cristian · Moreno Jose · Valdez Juan · Quiroga Jose · Pacheco Jesus · Victor H. Benitez

Abstract

This paper describes the design and implementation of a hydroponic system prototype using IoT-connected embedded devices for real-time monitoring. By integrating Autonomic Computing principles, the system is capable of self-maintenance, auto-monitoring, self-regulation, and self-repair — enabling efficient and optimal use of its resources without manual intervention. The prototype demonstrates how low-cost embedded hardware and autonomic software techniques can be combined to produce a scalable, intelligent agricultural system.
