Autonomic Hydroponic System

Methodology & Technical Approach

Traditional hydroponic systems require constant manual oversight — monitoring nutrient levels, pH, water temperature, and lighting schedules. This project set out to remove that dependency by building a self-managing prototype that applies Autonomic Computing principles to agricultural IoT — enabling the system to monitor, adapt, and repair itself without human intervention.

The system was built around IoT-connected embedded devices that continuously collect sensor data and trigger automated responses based on defined thresholds — bringing the four pillars of autonomic computing (self-monitoring, self-regulation, self-healing, and self-optimisation) into a practical agricultural context.

01

Sensor Network & Electronics Design

The hardware layer consisted of embedded microcontrollers connected to an array of environmental sensors measuring pH levels, nutrient concentration, water temperature, humidity, and ambient light. The electronics were designed and assembled to enable reliable continuous sensing, with careful attention to noise reduction and signal integrity in a wet environment.

02

Real-Time Data Acquisition

Sensor readings were collected at regular intervals and streamed to a monitoring layer in real time. This continuous data flow was the foundation for both live visualisation and the autonomic decision logic — ensuring the system could respond to environmental changes as they occurred rather than on a fixed schedule.

03

Autonomic Computing Integration

The control logic implemented the MAPE-K loop (Monitor, Analyse, Plan, Execute — with a shared Knowledge base), which is the standard framework for autonomic systems. When sensor readings deviated from optimal ranges, the system automatically triggered corrective actions — adjusting nutrient dosing pumps, activating grow lights, or alerting for manual intervention when an issue fell outside automated recovery.

04

Monitoring Interface

A real-time dashboard was built to visualise live sensor streams, system status, and event logs — giving operators visibility into what the autonomic system was doing and why. This was critical for validating system behaviour and building trust in automated decisions.

My Role in This Project

As part of a multi-disciplinary research team, my contributions focused on the research foundation and electronics design — including the sensor network architecture, embedded hardware selection and assembly, and the integration of IoT devices with the monitoring layer. The work was conducted collaboratively with co-authors spanning software, agronomy, and systems engineering.

Results & Outcomes

The prototype successfully demonstrated that Autonomic Computing principles can be effectively applied to an agricultural IoT context. The system operated continuously, responding to environmental changes in real time without manual intervention — validating the core hypothesis of the research.
