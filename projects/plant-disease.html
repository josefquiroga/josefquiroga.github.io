Plant Disease Classification

Methodology & Technical Approach

The core challenge in plant disease classification is building a model that can reliably distinguish between healthy and diseased leaf tissue across multiple plant species — a task that requires the model to learn subtle visual patterns in texture, colour, and lesion morphology. A Convolutional Neural Network (CNN) was chosen as the architecture because of its proven ability to extract spatial hierarchies of features from image data.

The project followed a structured ML pipeline from raw data through to a validated, evaluated model:

01

Data Collection & Preprocessing

A dataset of over 20,000 labelled leaf images was used, spanning multiple plant species and disease categories. Images were resized to a consistent resolution, normalised to the [0,1] pixel range, and split into training, validation, and test sets.

02

Data Augmentation

To improve generalisation and reduce overfitting on a relatively small dataset, augmentation techniques were applied during training — including random horizontal and vertical flips, rotations, zoom, and brightness adjustments. This artificially expanded the effective training set and exposed the model to greater visual variety.

03

Model Architecture

The CNN was built using TensorFlow and Keras, consisting of multiple convolutional blocks (Conv2D + ReLU + MaxPooling), followed by dropout layers for regularisation, a flattening layer, and a dense softmax output layer for multi-class classification. The architecture was iteratively tuned to balance depth with computational efficiency.

04

Training & Optimisation

The model was trained using the Adam optimiser with categorical cross-entropy loss. Early stopping was applied based on validation loss to prevent overfitting, and learning rate scheduling was used to fine-tune convergence in later epochs.

05

Evaluation

Model performance was assessed on a held-out test set using accuracy, precision, recall, and confusion matrix analysis across disease classes — identifying which categories the model handled well and where misclassifications occurred most frequently.

Results & Metrics

The final model achieved strong performance across the test set, demonstrating that a well-regularised CNN trained with augmented data can effectively distinguish plant diseases from visual leaf imagery alone.

89% Test Accuracy On held-out test set
20K+ Training Images Across multiple species
Multi Class Classification Healthy vs. multiple disease types
CNN Architecture Custom built with TensorFlow/Keras

The 89% accuracy result demonstrates the viability of deep learning for agricultural diagnostics — a domain where traditional methods rely on trained agronomists conducting manual inspections. Automated classification at this accuracy level could meaningfully accelerate disease detection and help growers intervene earlier, reducing crop loss.
