Methodology & Technical Approach

This project extended the foundational RFM dashboard work into a full unsupervised machine learning pipeline — applying K-Means clustering directly to the normalised RFM vectors to automatically discover meaningful customer behavioural cohorts from real payment transaction data processed at DataMesh Group.

The core limitation of RFM in isolation is that it reduces each customer to a three-dimensional vector, which loses nuance when viewed as a simple score. The insight here was to treat those three dimensions as coordinates in a feature space and let clustering algorithms find the natural groupings — rather than applying arbitrary scoring tiers.

01

Data Ingestion & RFM Feature Engineering

Raw transaction records were sourced from an AWS relational database containing credit and debit card payments across DataMesh's merchant network. A Python pipeline computed Recency (days since last transaction), Frequency (total transaction count), and Monetary (average transaction value) for each customer, across 2,107 distinct segments — locations, categories, brands, chains, and merchants.

02

Normalisation via Z-Score Standardisation

RFM values were standardised using Z-score normalisation within each segment, creating a comparable distribution across all customers regardless of segment size or transaction volume. This placed each customer in a normalised 3D RFM space suitable for distance-based clustering.

03

K-Means Clustering

The K-Means algorithm was applied to the standardised RFM vectors. The optimal number of clusters was evaluated using the elbow method on within-cluster sum of squares (WCSS) and validated with silhouette scores — arriving at k=5 cohorts that produced the most interpretable and business-meaningful separation across the customer base.

04

Cohort Interpretation & Profiling

Each cluster was profiled by cross-referencing its centroid coordinates with the raw transaction patterns — identifying the actual purchasing behaviours, categories, time-of-day patterns, and merchant types that characterised each group. This is where the most valuable insight emerged: distinct, human-interpretable customer personas surfaced directly from the data.

05

API & Dashboard Integration

Cluster assignments were stored in a dedicated PostgreSQL database and exposed via a Node.js REST API. The React dashboard built collaboratively with DataMesh's frontend team allowed stakeholders to explore segment-level RFM distributions, customer group compositions, and drill down from cohort to individual customer profiles.

Discovered Customer Cohorts

The most compelling output of this project was the emergence of interpretable, real-world customer personas directly from unlabelled transaction data — no manual rules or prior assumptions required. The five cohorts discovered were:

🔧 Tradies
High-frequency early morning buyers — energy drinks, meat pies, hardware stores, and petrol. Consistent daily transaction patterns, low individual transaction value but very high frequency. A distinctly Australian working-class consumer cohort identifiable purely from their purchase categories and time-of-day behaviour.
R: HIGH F: VERY HIGH M: LOW
💼 Young Professionals
Fill the car with petrol, go to restaurants, café visits, gym memberships, weekend dining. High average transaction value, moderate frequency, very recent purchasing behaviour. This cohort's spend profile revealed strong category concentration in food service, fuel, and fitness — a clear urban professional lifestyle signal.
R: VERY HIGH F: MODERATE M: HIGH
🚗 Budget Families
Own cars but frequent fast food chains — McDonald's, KFC, Hungry Jack's — alongside supermarket runs and petrol stops. Middle-to-lower income profile with consistent, predictable transaction patterns. High frequency spend but concentrated in lower-cost merchants, indicating value-driven purchasing decisions.
R: MODERATE F: HIGH M: MODERATE
🛍️ Occasional Shoppers
Low frequency, highly variable spend. Transactions are spread across many categories with no clear dominant pattern — likely capturing irregular or infrequent card users whose behaviour doesn't coalesce around any consistent lifestyle signal. Identified as a potential churn or re-engagement target segment.
R: LOW F: LOW M: VARIABLE
⭐ High-Value Loyalists
Consistently high scores across all three RFM dimensions — recent, frequent, and high-spending. This is the smallest but most commercially valuable cohort, representing the organisation's best customers. Their transaction footprint spans restaurants, retail, and services with above-average individual transaction values and very high retention signals.
R: VERY HIGH F: HIGH M: VERY HIGH

Results & Impact

The project delivered a production-ready, end-to-end system: from raw AWS transaction records through a Python ML pipeline, into a PostgreSQL database, served via a Node.js API, and visualised in a React dashboard. The K-Means segmentation layer extended the original RFM dashboard into something substantially more powerful — moving from descriptive metrics to automated, interpretable customer intelligence.

5 Cohorts Discovered Interpretable, human-meaningful personas
2,107 Segments Processed Locations, brands, merchants, chains
E2E Full Pipeline AWS → Python → PostgreSQL → API → React
0 Manual Labels Cohorts discovered entirely unsupervised

The business value was clear: instead of treating all customers identically, DataMesh could now tailor insights and recommendations to each cohort's behavioural profile — enabling merchants to understand which customer types they attract, how to retain them, and how to identify growth opportunities within each segment. The "Tradies" cohort in particular was a commercially significant discovery, representing a highly loyal, high-frequency group that was invisible in aggregate transaction data.
